# ☕ Coffee Shop Acquisition Financial Model

An interactive financial analysis tool for evaluating multi-location retail acquisitions. Built with Python and Streamlit.

## 🎯 Features

- **5-Year Financial Projections**: Revenue, expenses, cash flow, and cumulative returns
- **Three Scenario Analysis**: Pessimistic, Base Case, and Optimistic scenarios
- **Real-Time Calculations**: IRR and payback period with instant updates
- **Interactive Assumptions**: Adjustable sliders for all key variables
- **Visual Analytics**: Beautiful charts powered by Plotly
- **Export Functionality**: Download projections as CSV for further analysis

## 📊 What It Does

This model helps analyze small business acquisitions by projecting:
- Revenue growth under different scenarios
- Operating expenses (COGS, Labor, Rent, Other)
- Debt service payments
- Annual and cumulative cash flows
- Return on investment (IRR)
- Break-even timeline

Perfect for:
- Small business buyers
- Investment analysts
- Financial advisors
- Real estate investors
- Portfolio demonstrations
